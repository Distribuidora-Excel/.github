# Distribuidora Excel

Diexsa es una empresa de distribución con sede en Monterrey, México. En esta organización vive el
software que la hace funcionar: el sistema de administración (ERP), la tienda en línea
[diexsa.mx](https://diexsa.mx) y la aplicación de almacén para los equipos de mano.

Los repositorios son privados: contienen la operación de la empresa. Este perfil existe para que
quien llegue aquí sepa qué es y a quién escribir.

## Cómo trabajamos

- **.NET 10**, C#, Azure y Microsoft 365.
- Todo cambio entra por pull request con la integración continua en verde.
- Conventional Commits, en español.
- Sin secretos en el código: identidades federadas y Azure Key Vault.
