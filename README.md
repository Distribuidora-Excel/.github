# .github

Archivos que GitHub aplica a todos los repositorios de la organización que no tengan el suyo
propio: `SECURITY.md`, `CONTRIBUTING.md`, la plantilla de pull request y las de issues. En
`profile/` está el perfil público de la organización.

Es público a propósito: GitHub lo exige para que los archivos se hereden. Nada de aquí describe
cómo están hechos los sistemas.
